# Twinkle Tutor — twinkletutor.com

Website for Twinkle Tutor: live 1-on-1 online tutoring for US students, Kindergarten to 12th Grade.
It's a static site with no database or server code, hosted free on GitHub Pages.

## Folders

| Path | What it is |
|---|---|
| `data.py` | Content: states (standards & tests), grades, subjects, exams |
| `build.py` | Page templates, prices (`PLANS`), email (`EMAIL`), form address (`FORM_ENDPOINT`) |
| `docs/` | The finished website that GitHub Pages serves (generated by `build.py`) |
| `docs/assets/style.css` | Colors, fonts and layout |
| `docs/assets/main.js` | Mobile menu, forms, pricing toggle |

## Make a change

1. Edit `data.py`, `build.py`, `docs/assets/style.css` or `docs/assets/main.js`.
2. Rebuild (needs Python 3 only, nothing to install):

   ```bash
   python3 build.py
   ```

3. Preview at http://localhost:8000/us/:

   ```bash
   python3 -m http.server 8000 --directory docs
   ```

4. Commit and push (or upload the changed files on GitHub). The live site updates in a minute or two.

Don't edit the HTML files in `docs/` by hand; `build.py` overwrites them on every build.

## Hosting on GitHub Pages

1. Repository **Settings → Pages**: Source **Deploy from a branch**, branch **main**, folder **/docs**, then **Save**.
2. Custom domain: `twinkletutor.com` (the `docs/CNAME` file sets this), then tick **Enforce HTTPS** once it's available.
3. DNS at Hoster.pk:

   | Type | Name | Value |
   |---|---|---|
   | A | `@` | `185.199.108.153` |
   | A | `@` | `185.199.109.153` |
   | A | `@` | `185.199.110.153` |
   | A | `@` | `185.199.111.153` |
   | CNAME | `www` | `YOUR-GITHUB-USERNAME.github.io` |

   Remove the old A record pointing to `45.79.150.137`.

The site uses root paths (`/assets/...`, `/us/...`), so it needs the custom domain; it won't display correctly at `username.github.io/repo-name`.

## Forms

GitHub Pages can't receive form submissions. Create a free form on a service such as [Formspree](https://formspree.io),
put its URL in `FORM_ENDPOINT` in `build.py`, and rebuild. Until then, submitting the free trial or contact form
on the live site shows an error message and nothing is delivered.
