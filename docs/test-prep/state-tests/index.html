Overview

About the State Tests

Every state gives annual tests in Grades 3–8 and in high school. Examples include STAAR in Texas, CAASPP in California, FAST in Florida, the New York State Tests and Regents Exams, and PSSA and Keystones in Pennsylvania.

Format

What's tested

ELA / Reading

Comprehension, vocabulary and written responses.

Math

Grade-level standards and multi-step problems.

Science

Tested in selected grades (often 5, 8 and high school).

End-of-Course

High school EOC or Regents exams in some states.
